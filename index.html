Bedside Bayes Engine ／ 尤度比・情報量・到達可能域

身体診察はどこまで確率を動かせるか 事前確率と決定閾値を置き、所見を一つずつ積む。左に伸びれば除外へ、右に伸びれば確定へ。
薄い雲は「まだ取っていない所見を全部取ったときに到達しうる確率の分布」— 診察の射程そのもの。

v2.6.1

1. 設定 PRIOR & THRESHOLDS

同一の生理学的機序に属する2つ目以降の所見は logLR × κⁿ に減衰。 κ=1 が素朴ベイズ（教科書どおりのLR掛け算）、κ=0 は「同じ機序は最強の1つだけ採用する」と同値。 相関の程度が分からないときは κ を下げるほど保守的になる。

2. 所見をとる FINDINGS

＋ 所見を追加・LRを差し替える
追加した所見は 自作 として扱われ、情報利得の計算にも即座に入る。手元のMcGee／JAMA Rational Clinical Examination の値に総入れ替えして、自分の教育用パネルを作れる。

3. 次の一手 EXPECTED INFORMATION GAIN

次にどの診察をすれば、いちばん迷いが減るかの順番です。
やる前は陽性か陰性か分かりません。そこで陽性だった場合と陰性だった場合の両方を、それぞれの起こりやすさで重みづけして平均し、確率がどれだけ動きそうかを1つの数にしています（単位 bit）。「期待」が付くのはこのためです。
1 bit ＝ 五分五分の迷いが、ひとつ完全に解けるだけの情報量。0.1 bit を切ると、確率はほとんど動きません。
ただし「確率が動かない」ことと「判断が変わらない」ことは別です。閾値のすぐ近くにいれば、わずかな動きでも除外域・確定域に入ります。そのため各行には 「判断が変わる確率」 を併記しています ── 実務ではこちらが決め手になることが多いので、bit が小さくてもこの数字が大きい所見は見逃さないでください。
bit とは何か ── LR とオッズは知っているが bit は初めて、という方へ

まず、すでにご存じのものから。 尤度比（LR）は「その所見が確率をどれだけ動かすか」を表します。これは所見の性質で、患者によりません。
bit はその次の話で、「その動きによって、この患者についての迷いがどれだけ晴れたか」を表します。 こちらは患者によって変わります。同じ所見でも、誰に使うかで価値が違うからです。

1. 「迷いの大きさ」を数で表す

確率が 50% のとき、あなたは最大限に迷っています。この五分五分の迷いを 1 bit と決めます。 0% か 100% に振り切れていれば、迷いは 0 bit ── もう迷っていません。

診察をすると、患者はこの曲線の上を左右に動きます。動いた先で山がどれだけ低くなったかが、その診察で得られた情報です。

2. なぜ「期待」が付くのか

やる前は、陽性になるか陰性になるか分かりません。だから 「陽性だった場合に減る迷い」と「陰性だった場合に減る迷い」を、 それぞれの起こりやすさで重みづけして平均します。この平均が「期待情報利得」です。

Benish はこれを、「最終的に診断を知ったときの驚きを、検査が平均してどれだけ減らすか」と言い換えています（Methods Inf Med 2009; PMID 19562229）。

3. ここが本題 ── LR が大きい所見が、価値が高いとは限らない

肺炎を 30% 疑っている患者に、4つの所見をそれぞれ取ったとします。

所見LR+LR−期待情報利得
ヤギ音6.170.960.011 bit
クラックル2.000.800.024 bit
打診濁音（肺炎）2.62―0.000 bit
バイタル異常1.300.250.047 bit

LR+ が最も大きいヤギ音が、最も価値が低い。LR+ 1.30 のバイタル異常が、その4倍の情報をもたらします。

理由は感度です。ヤギ音の感度は約5%。98% の確率で「陰性」になり、その陰性は LR− 0.96 ＝ ほとんど確率を動かしません。 つまり「たまに出れば強いが、ほとんど出ない」所見です。平均すれば、得られる情報はわずかになります。
逆にバイタル異常は LR+ こそ小さいものの、陰性に意味があり（LR− 0.25）、しかも高い頻度で決着がつく。だから平均では勝ちます。
打診濁音が 0.000 bit なのは、LR− が報告されていない（＝陰性から何も学べない）ためです。

4. 同じ所見でも、患者によって価値が変わる

同じヤギ音を、事前確率の違う3人に使ってみます。

事前確率陽性なら陰性なら期待情報利得
5%24.5%4.8%0.003 bit
30%72.6%29.1%0.011 bit
80%96.1%79.3%0.007 bit

同じ所見・同じ尤度比なのに、得られる情報は3倍以上違います。 迷っている患者（50%に近い）ほど、同じ診察から多くを得られる。ほぼ決まっている患者に同じ所見を取っても、ほとんど何も増えません。

感度・特異度や ROC 曲線下面積（AUC）は事前確率に依存しない指標なので、この違いを表せません。 Benish は 「AUC は診断情報の尺度ではない」と明言しています（Methods Inf Med 2003; PMID 12874659）。 「この所見はよい所見か」ではなく「この患者にいまこの所見を取る価値があるか」を問うなら、bit が要ります。

5. なぜパーセントではなく bit なのか

同じ「10ポイントの動き」でも、いまいる場所で意味がまるで違うからです。

50% → 60% ： 迷い 1.000 → 0.971　＝ 0.03 bit しか減らない
89% → 99% ： 迷い 0.500 → 0.081　＝ 0.42 bit 減る

どちらも10ポイントですが、迷いの減り方は 14倍 違います。パーセントの差では、この違いを取り違えます。

6. 数字の感覚

0.5 bit 以上なら大きく動く。0.1〜0.3 bit ならそれなり。0.05 bit を切ると確率はほとんど動きません。

⚠️ ただし bit が小さいからといって切り捨てないでください。 閾値のすぐそばにいるときは、わずかな動きでも除外域・確定域に入ります。 各行の「判断が変わる確率」を必ず併せて見てください。

出典と位置づけ

情報理論を診断検査に応用する考え方は、William A. Benish による一連の仕事として確立しています ── 相対エントロピー（1999, PMID 10231083）、情報グラフ（2002, PMID 12061117）、 相互情報量（2003, PMID 12874659）、直観的・公理的な導出（2009, PMID 19562229）、 そして総説（Entropy 2020, PMID 33285872, PMC7516534, オープンアクセス）。
ただしこれらは医療情報学の文献であり、ベッドサイドの身体診察の教科書（McGee・Bates・Sapira）は尤度比までで、bit は使っていません。 身体診察の一手ごとの価値を bit で順位づけして提示する試みは、少なくとも一般的ではありません。
